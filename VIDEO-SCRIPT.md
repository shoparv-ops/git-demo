# Video Script — Git Add, Commit, and Push

**Target length: 30–40 seconds**

Hello! In this video, I will demonstrate three basic Git commands: add, commit, and push.

First, I use `git add .` to stage the changes I want to include.

Next, I use `git commit -m "Add Git workflow demo"` to save those staged changes in my local repository.

Finally, I use `git push origin main` to upload my commit to GitHub.

As you can see, the files and commit are now available in the remote repository.

That is the basic Git workflow: add, commit, and push. Thank you!

## Recording guide

- Show the project folder in Visual Studio Code or File Explorer.
- Open the terminal in the project folder.
- Run each command slowly, leaving the output visible.
- Refresh the GitHub repository page at the end.
- Keep the recording between 30 and 40 seconds.
