# Presentation: Git Add, Commit, and Push

## Introduction

Hello! In this presentation, I will demonstrate how to add, commit, and push changes using Git and GitHub.

## Step 1 — Add

The command `git add demo-note.txt` stages the file. This means I have selected the changes that I want to include in my next commit.

## Step 2 — Commit

The command `git commit -m "Update demo note"` saves the staged changes as a commit in my local repository. The message explains what was changed.

## Step 3 — Push

The command `git push origin main` uploads my local commit to the remote repository on GitHub.

## Conclusion

Now the changes are available on GitHub. The basic workflow is:

**Add → Commit → Push**
