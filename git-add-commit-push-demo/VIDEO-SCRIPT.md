# Video Script (approximately 35–40 seconds)

**0–5 seconds — Introduction**

"Hello! In this video, I will demonstrate the basic Git workflow: add, commit, and push."

**5–14 seconds — Add**

"First, I use git status to check my changes. Then I use git add demo-note.txt to stage the file."

**14–24 seconds — Commit**

"Next, I use git commit with a message. This saves the staged changes in my local Git repository."

**24–33 seconds — Push**

"Finally, I use git push origin main to upload my commit to GitHub."

**33–40 seconds — Result**

"Now I can refresh GitHub and see my updated file and commit. That is the basic Git workflow. Thank you!"

## What to show on screen

1. The project folder in the terminal.
2. The changed `demo-note.txt` file.
3. `git status` before staging.
4. `git add demo-note.txt` and `git status` again.
5. The commit command and its output.
6. The push command and its output.
7. The updated file or commit history on GitHub.

Speak naturally and keep the terminal text readable.
